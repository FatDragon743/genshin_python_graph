# 原神抽卡记录分析

## 功能

- **扫码登录 / 增量同步**：米游社登录，拉新记录并保留本地更早历史
- **欧非分析**：角色/武器/常驻/集录四池；区分限定与常驻（歪/不歪）；长期 + 近期运势
- **出图保存**：分析结果可保存为图片

## 安装

```bash
pip install -r requirements.txt
python test3.py
```

浏览器会打开 `http://127.0.0.1:8765/`（本地网页：扫码 / 同步 / 欧非分析）。
旧版 Tk 界面仍可通过 `python -c "from wish_app.gui import run; run()"` 启动。

## 使用

1. 首次：点击「米游社扫码登录」→ 米游社 APP → 我的 → 扫一扫并确认（凭证写入 `data/session.json`）  
2. 之后打开程序会自动恢复登录，可直接「同步抽卡记录」  
3. 点击「欧非分析」查看四池总结（歪/不歪、长期与近期运势）

抽卡接口使用现行域名 `public-operation-hk4e.mihoyo.com`。仅国服；`data/session.json` 含敏感信息勿提交。凭证过期后再扫码即可。

## 同步策略

- **默认增量**：先读本地库，从最新往旧拉；碰到已有官方 `id`（或无 id 时的指纹）即停
- **信任本地历史**：官方接口大约只有近 1 年；更早记录保留自本地旧表（根目录导出 / `data/原神祈愿记录_local.xlsx`）
- 同步前会自动把旧历史与 UID 主库拼成种子，再与线上合并（窗口前全留，窗口内对齐线上 id）
- 范围写入 `__meta`（`pool_cursors` / `last_sync_range` / `seed_sources`）

## 合并规则摘要

- 主键：官方 `id`；旧数据无 id 时用 `时间|名称|星级|类别|卡池` 指纹
- 合并后按时间重算「总次数」「保底内」
